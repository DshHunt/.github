# DSH Hunt organization profile

This repository maintains the public [DSH Hunt GitHub organization profile](https://github.com/DshHunt).

- [`profile/README.md`](profile/README.md) is displayed on the organization's Overview page.
- [dshhunt.com](https://dshhunt.com) is the official plugin directory and evidence website.
- [`DshHunt/community`](https://github.com/DshHunt/community) is the public home for plugin submissions, evidence corrections, methodology feedback, and the roadmap.

To update the organization introduction, edit `profile/README.md`. Keep the description and links consistent with the public website and community documentation.
