# DSH Hunt

**Discover DeepSeek Harness plugins. Explore the evidence.**

DSH Hunt is an independent community project for discovering **DeepSeek Harness (DSH) plugins** and understanding their source structure and changes.

[Browse plugins](https://dshhunt.com/plugins) · [Read the methodology](https://dshhunt.com/methodology) · [Join the community](https://github.com/DshHunt/community)

## What you'll find

- **Plugin discovery** — explore the directory and follow links to original repositories.
- **Source-linked evidence** — inspect package and manifest paths, declared metadata, Patch references, and analysis coverage tied to a fixed source commit.
- **Change context** — explore [recorded version changes](https://dshhunt.com/changes), with source updates kept separate from corrections to earlier reports.

Reports make the source easier to inspect and explain what was checked. Read the [guide to static evidence](https://dshhunt.com/guides/read-static-evidence) to understand the fields and their limits.

## What the evidence means

DSH Hunt uses static analysis. Reports describe source files at a specific commit; plugins are not installed, built, or run as part of the report. Inclusion is not a security endorsement or a runtime compatibility guarantee. Coverage limits are part of the evidence, and “not checked” does not mean “not present.”

DSH Hunt is not affiliated with or endorsed by DeepSeek.
